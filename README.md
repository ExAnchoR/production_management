# Production Management

A small Python-based production management system for tracking staff, products, materials, and production history.

## Features

- Manage staff records
- Manage raw materials
- Manage products
- Track production runs and history
- View records by staff, material, and product

## Run

```bash
python main.py
```

## Project structure

- `controller/` – application logic and menu handlers
- `model/` – data models
- `view/` – UI/menu layer
- CSV files – persisted data for staff, materials, products, and production history
